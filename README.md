This repository contains the **frontend** and **backend** of the NVP application.  
The project provides user authentication, employee management, CSV import, and real-time notifications.

---

## Frontend: nvp-frontend

**Tech Stack:** Node.js, Express.js, JWT, bcrypt, Socket.io

### Features
- User login with JWT
- CRUD Employee
- Queue handling for CSV import
- Token validation middleware

### Running Backend
```bash
cd nvp-frontend
npm install
npm run dev
